# Decode Dreams 📱⚡

A full-stack mobile application that interprets complex user inputs through customizable, multi-perspective analysis frameworks.

## 🚀 Key Features
* **Multi-View State Engine:** Instant switching between analytical perspectives without UI latency.
* **Native Audio & Voice:** Integrated voice recording and ambient soundscape playback using Expo Audio.
* **Offline Caching:** Fast local storage management using SQLite for performance.
* **EAS Build Pipeline:** Automated mobile build workflows deployed via Expo Application Services.

## 🛠️ Tech Stack
* **Frontend:** React Native, Expo, TypeScript
* **Backend:** Node.js, Express, REST APIs
* **State & Storage:** React Context, SQLite
